# Data Analytics Specialization

This repository contains the activities, exercises, and projects completed during my Data Analytics specialization course.  
The course is organized into 13 sprints, covering SQL, databases, statistics, Python, Power BI, and API data consumption.

## Repository contents

Each sprint includes:
- The original SQL script or notebook files.
- A PDF report with the results and conclusions.
- An `nbviewer` link to render the notebook files directly in the browser.
